- ## 1부
	- ### 1장
	- 칼로리를 계산해서 음식의 섭취량을 결정하고 운동량을 계산하는것은 잘못되었다.
		- 많이 먹는 증상이 생긴 것은 포만감을 주는 호르몬이 둔감해졌기 때문이다.
			- 혈액내에 포도당과 지방산을 제대로 이용을 못하기 때문
		- 피하지방의 기능부전
		- 지속적인 저칼로리 식단의 문제점
			- 스트레스 호르몬인 코르티솔을 분비->우울감,수면장애->탄수화물 갈망->폭식과 과식
		- 영양소의 조정이 중요하다.
			- 저칼로리 식단 -> 기초대사량의 저하 ->근육량의 저하 ->요요현상 ->백혈구 수치 저하 -> 면역력 저하
				- 상승
					- 코르티솔
					- 그렐린
				- 저하
					- 인슐린, 렙틴, CCK, PYY
					- 갑상샘 호르몬
					- 테스토스테론
					- 총에너지소비량
					- 식후 열 발생
					- 활동 열 생성
					- 근육량
		- 안정시대사율을 떨어뜨리지 않고 체지방을 줄여야 요요현상이 생기지 않는다.
			- 안정시 대사율 : 신체활동 없이 휴식을 취하고 있을때 내 몸에서 신체기능과 항상성을 유지하기 위해 기본적으로 필요한 에너지량을 말한다. 기초대사율 혹은 기초대사량이라는 개념과 혼용해서 쓰이기도 한다. 다만, 차이점은 기초대사율은 24시간 안정된 상태에서의 에너지 소비량이고 안정대사율은 식사, 화장실 이용, 스트레칭 정도의 가벼운 활동이 포함된 에너지 소비량이다.
		- 정제탄수화물로 체운 칼로리 과잉 섭취가 원인
	- ### 2장
	- 체중으로 비만을 진단하는것은 잘못됐다.
		- 비만 지표의 확인으로써 BMI는 잘못되었다.
		- 대사증후군 진단 기준으로 비만을 확인할것
			- 허리둘레 : 남성 90CM 이상, 여성 80CM이상
			- 혈압 : 130/85mmHg 이상
			- 공복혈당 : 100mg/dL 이상
			- 중성지방 : 150mg/dL 이상
			- 고밀도지단백(HDL) 콜레스테롤 : 남성 40mg/dL 미만, 여성 50mg/dL 미만
		- 체중이 늘었다는것
			- 인슐린저항성
			- 만성염증
			- 피하지방
			- 기능부전
- ## 2부
	- ### 1장
		- 신진대사가 무너지면 '비만'이 된다.
		- 비만은 많이 먹어서 생기는 병이 아니다. 몸이 망가졌기 때문에 많이 먹는 증상이 나타나고 그로 인해 체중이 증가하는 만성질환이다.
		- 우리의 몸은 기본적으로 잉여에너지가 체내로 들어온 만큼 몸이 에너지소비량을 평소보다 더 늘려 항상성을 유지한다.
		- 우리의 몸은 새로운 환경에 적응하면서 식습관과 생활습관이 바뀌면 체중이 조금씩 늘어난다.
		- 살이 잘 안찌는 사람들은 대사 유연성이 좋다.
			- 포도당과 지방을 적시에 잘 꺼내 쓰는 몸
		- 반대로 살이 잘찌는 사람들은 대사 유연성이 안좋다.
			- 포도당과 지방을 적시에 잘 쓰지 못하는 몸
		- 대사유연성을 결정하는 것은 유전적 요인이 환경보다 더 강하게 영향을 미친다.
		- 환경적 요인으로는 주로 칼로리 밀도가 높고 입안에서 살살 녹기까지 하는 정제가공식품의 증가가 주된 원인이다.
		- 결국 유전적으로 비만해지기 쉬운 소인을 타고난 사람이 이러한 비만 유발 환경에 노출되면서 나날이 비만해지는 것
		- 당대사와 지방대사의 효율이 관건
			- 인체는 포도당을 주로 에너지원으로 쓰지만 당이 떨어지면 비축해두었던 지방을 꺼내 에너지원으로 쓴다.
		- 공복상태에서 식사로 탄수화물을 섭취하면 넘치는 당을 우선적으로 쓰면서 동시에 체내 지방연소를 억제한다.
		- 당이 떨어지고 나서야 지방을 분해해서 연료로 사용한다.
		- 낮 시간에 포도당대사가 주로 일어난다.
		- 밤시간에 지방 대사가 주로 일어난다.
		- 문제는 쉬지 않고 먹으면서 오래 앉아 있기 때문이다.
			- 우리 몸에서 대사유연성을 결정하는 가장 중요한 조직
				- 골격근
					- 근육이 식사 후에 올라간 혈당을 적극적으로 사용하지 않아서 식후 고혈당이 오래 지속되면 대사 유연성이 떨어진다.
				- 피하지방
					- 야식을 먹고, 아침에 일어나자마자 바로 식사를 해 지방산이 나올 틈이 없다.
			- 결론적으로 밤낮으로 지방산을 쓸 조건이 활성화가 되지 않는다.
		- 신체 활동량 대비 지속적으로 음식(특히 탄수화물)을 많이 먹는다면 지방조직에서 지방을 꺼내 쓰지 못할 뿐 아니라 결국 그러한 기능에도 고장이 생긴다.
		- 혈당을 올리는 음식을 쉬지 않고 먹고 하루 종일 의자에 앉아 있는 생활이 이어지다 보니 살이 찌게 된다.
		- 대사 유연성을 예전 수준으로 회복해야 살이 빠진다.
			- 골격근의 기능을 회복할것
			- 12시간 이상의 공복을 유지할것
			- 간헐적 단식을 할것
			- 잠든 지방조직의 기능을 회복(지방산)할것
		- 대사 유연성의 좋고 나쁨은 호흡률로 평가할 수 있다.
			- 산소 소모량:배출한 이산화 탄소 생성량
				- 지방만 에너지원으로 이용한 호흡률 = 0.7
				- 포도당만 에너지원으로 이용한 호흡률 = 1.0 언저리
			- 대사 유연성이 좋다 = 호흡률 변화가 크다
			- 대사 유연성이 안좋다 = 호흡률 변화가 작다
			- 식사량을 줄이고 신체 활동량을 늘린다 -> 호흡률이 낮아진다 -> 대사유연성이 개선된다 -> 인슐린 분비량이 줄어든다.
	- ### 2장
		- 모든 것은 인슐린 저항성에서 비롯된다.
		- 몸이 망가지면서 살이 찌는 현상이 나타난다.
		- 골격근과 지방조직의 작동 능력 저하 -> 대사 유연성 하락 -> 자주 먹게 되고 덜 움직이는 증상이 나타남
			- 대사 유연성 하락 -> 미토콘드리아 제기능 불가 = **인슐린 저항성**
				- 피하지방의 기능부전 유발
				- 지방간 유발
				- 근육 내 지방축적 유발
		- 인슐린 분비 -> 합성 모드
			- 인슐린이 조직에 주는 영향
				- 췌장의 베타세포에서 인슐린 분비 -> 혈액으로 이동 -> 혈당을 낮춰줌
				- 간과 근육
					- 포도당을 글리코겐으로 만들어 비축
				- 지방조직
					- 지방 분해 억제
					- 혈액으로 유리지방산 방출 억제
		- 공복 상태
			- 인슐린 수치 바닥
			- 인슐린이 작동 하지 않음 -> 분해 모드
			- 간
				- 비축해둔 글리코겐을 분해 -> 포도당 -> 혈액으로 방출 -> 혈당 유지
				- 글리세롤, 아미노산을 분해 -> 포도당 -> 혈액으로 방출 -> 혈당 유지
			- 뇌가 먼저 포도당을 우선순위로 가져감
				- 나머지 하위 기관들은 지방조직에서 방출하는 유리지방산을 연료로 사용
		- 식사를 한 상태
			- 탄수화물의 소화 흡수 -> 혈액 내 포도당 상승 = 혈당 상승
			- 혈당이 일정 수준에 도달할 경우 -> 인슐린 분비
			- 인슐린 농도의 상승 -> 합성 모드
				- 지방조직에서 유리지방산 방출 억제
				- 간에서 포도당 방출 억제
			- 골격근, 간, 지방조직 중 가장 적극적으로 포도당을 유입하는 기관은 골격근
			- 근육
				- 흡수한 포도당 -> 에너지원 사용 -> 남은 포도당 글리코겐 형태로 비축
				- 합성 모드에서 근육이 혈액 내 포도당의 약 70~80% 흡수 -> 혈당 하락
				- 골격근이 식후 혈당을 떨어뜨리는데 가장 큰 역할을 수행
					- 식후에 가볍게 산책을 하는 등의 신체활동은 식후 혈당 조절에 아주 효과적
			- 간
				- 흡수한 포도당 -> 글리코겐 형태로 저장
				- 포도당 방출을 억제 -> 혈당 하락
			- 지방 조직
				- 흡수한 포도당 -> 중성지방으로 저장
				- 지방 분해 억제 작용 -> 유리지방산 방출 차단 -> 혈액 내 지방산 농도 하락 -> 포도당을 에너지원으로 더 많이 사용 -> 혈당 하락
		- 인슐린 저항성
			- 인슐린이 제 기능을 발휘하지 못하거나 작동 능력이 떨어진 상태
			- 인슐린 저항성 -> 혈당 하락에 지장 -> 췌장에서 혈당이 떨어지지 않는다고 판단 -> 인슐린 분비량 상승 -> 췌장의 베타세포의 무리 -> 베타세포 손상 ->인슐린 분비량 감소 -> 혈당 하락 실패 -> 당뇨
				- 쉬지 않고 먹는 일과가 나흘만 지속되어도 인슐린 저항성이 발생
			- 공복 혈당이 100mg/dl 초과 -> 체중관리를 통해 인슐린 저항성에 벗어나 당뇨병 발생을 막아야함
			- 인슐린 저항성 -> 대사 유연성 기능 저하
				- 대사 유연성을 결정하는 조직
					- 골격근
						- 골격근이 포도당을 잘 끌어다 쓰지 못함 -> 근육에 인슐린 저항성 발생
					- 피하지방
						- 지방세포가 더 이상 여분의 에너지를 흡수하지 못함 -> 피하지방에 인슐린 저항성 발생
						- 가장 마지막에 인슐린 저항성이 발생
					- 간
						- 간에 지방이 낌 -> 인슐린 저항성 발생
						- 제일 먼저 인슐린 저항성이 발생
				- 어느 조직에서 먼저 인슐린 저항성이 생기면 다른 조직의 인슐린 저항성을 유발해 결국 전신 인슐린 저항성으로 이어짐
			- 간
				- 공복 상태 - 분해 모드
					- 비축한 포도당 방출 -> 혈당 안정
				- 식후 상태 - 합성 모드
					- 포도당 흡수 -> 글리코겐 형태로 변환 & 비축
				- 간에 지방이 쌓일 경우
					- 인슐린 저항성 발생 -> 포도당의 지속적인 방출 -> 혈당 상승
					- 글리코겐 저장량 부족 발생 -> 뇌가 생존의 위협을 감지 -> 달달한 음식을 요구
					- 근육 단백에 있는 아미노산 분해 -> 포도당 생성 -> 근손실 (근육합성에 필수 영양 = 아미노산)
			- 근육
				- 골격근의 인슐린 저항성 -> 몸 전체의 신진대사에 영향
					- 골격근이 혈중 포도당을 70~80%흡수를 못하게 됨 -> 간과 지방조직으로 포도당이 더 많이 흘러감 -> 중성지방 생성 -> 지방간, 체지방 증가 -> 체중 증가
			- 지방조직
				- 인슐린 -> 지방분해 억제 -> 체지방 증가 -> 체중 증가
				- 근육과 간에 인슐린 저항성이 생겨 포도당을 흡수하지 못해도 아직 인슐린 저항성이 생기지 않은 피하지방은 여분의 에너지를 지방으로 저장
				- 지방세포의 증가는 한계가 있음 -> 여분의 에너지를 더 이상 비축하지 못하는 지점 도달 -> 염증 발생, 인슐린 저항성 발생
				- 피하지방의 인슐린저항성 -> 중성지방 분해 -> 유리지방산 방출 -> 혈액내 포도당과 유리지방산의 동시 증가 -> 에너지원들(포도당, 유리지방산)의 경쟁 발생 -> 지나친 경쟁으로 인한 에너지원 사용이 힘들어짐 -> 골격근의 에너지의 비효율적인 사용 발생 -> 대사유연성 하락 -> 인슐린저항성 악화
			- 고혈당과 고농도 유리지방산에 장기간 노출 -> 골격근 인슐린저항성 악화 -> 지방간 악화 -> 유리지방산의 내장지방 축적 -> 복부 비만, 간, 췌장, 심장, 혈관 등등 다른 조직에도 인슐린저항성을 발생 및 악화
				- 췌장의 베타세포 손상 가속화 -> 인슐린 분비 능력 저하 -> 당뇨
				- 심장근육에 지방
				- 중성지방 콜레스테롤 수치 상승
				- 염증과 산화 반응 -> 혈관 내피세포 손상 -> 심혈관질환
		- 인슐린 저항성의 징후
			- 체중증가
				- 벳살이 나오고 내장지방 비만 -> 인슐린 저항성
			- 허리둘레가 아래 수치가 넘어갈 경우 검사 필요
				- 남성 -> 90cm
				- 여성 -> 85cm
			- 검사시 체크 항목 및 아래 수치 이상일 경우 인슐린 저항성 가능성이 높다
				- 혈압
					- 수축기 혈압 130mmHg 이상
					- 이완기 혈압 85mmHg 이상
				- 공복혈당
					- 100mg/dL 이상
				- 당화혈색소
					- 5.7% 이상
				- 공복인슐린
					- 7uIU/mL 이상
				- 콜레스테롤
					- 130mg/dL 이상
				- 중성지방
					- 150mg/dL 이상
				- 요산

	- ### 3장
		- 피하지방이 제대로 작동을 못한다
		- 우리 몸의 혈관속에는 유리지방산이 떠나닌다.
			- 식사를 통해 외부에서 들어온다
			- 지방조직에 비축해두었다가 분해하여 혈액으로 방출된다
		- 음식 -> 지방 -> 소장 -> 라파아제에 의한 지방 분해 -> 지방산, 모노글리세라이드 -> 소장 점막세포에서 흡수 -> 중성지방으로 합성 -> 콜레스테롤, 인지질, 단백질과 결합 -> 킬로미크론(지단백) 생성 -> 림프순환 -> 혈액 -> 지단백리파아제가 킬로미크론을 분해 -> 유리지방산, 글리세롤 -> 세포가 지방산 흡수 -> 중성지방으로 합성 -> 저장
		- 공복시간 증가 -> 혈당 하락 -> 지방조직에서 유리지방산 방출, 간에서 VLDL에 중성지방을 실어 혈액을 방출 -> 에너지원 공급
		- 지방조직에서 분비하는 호르몬

				- 염증억제
				- 지방을 에너지원으로 사용하게 함

				- 식욕 조절
				- 렙틴분비량 상승 -> 식욕 억제 -> 신진대사 상승
				- 렙틴분비량 저하 -> 식욕 상승 -> 신진대사 하락
				- 당 조절
		- 피하지방의 기능부전
			- 혈액 속에 넘쳐나는 유리지방산이 간, 췌장, 내장지방, 골격근, 심장, 혈관에 쌓이면서 대사증후군, 지방간, 당뇨병, 심장질환으로 이어짐
			- 지방세포의 숫자는 성인이 되기 전 청소년기에 결정 이후 매년 약 10%씩 교체
			- 피하지방의 기능부전이 유발하는 것들
				- 식사 중간 중간 혈당을 높이는 간식을 끊임없이 먹으면서 하루 종일 꼼짝 않고 앉아 있고 거기다가 야식까지 더해지면 지방조직은 어쩔 수 없이 잉여에너지를 세포 내 지질방울에 꾸역꾸역 쌓아놓아야한다.
				- 지방세포의 크기가 계속 커지다가 세로운 지방세포가 만들어져 넘쳐나는 에너지를 더 이상 저장하지 못하게 된다면 지방세포는 기능부전에 빠지게 된다.
				- 지방세포가 기능부전에 빠지면 산소를 충분하게 공급받지 못해 저산소 상태에 빠진다.
				- 저산소 상태에 바지면 염증을 촉진하는 물질이 생성된다.
				- 염증이 생기면 면역세포가 활성화되서 염증반응을 더 촉진한다.
				- 염증반응이 심화되면 산화스트레스가 발생한다.
				- 산화스트레스로 인해 지방세포는 결국 사멸해버린다.

				- 지방분해가 억제가 되지 않기에 분해된 지방세포 즉 유리지방산들은 혈액으로 방출되어 간과 근육 내장으로 흘러 들어가 쌓인다.
				- 간과 근육 그리고 내장으로 흘러간 유리지방산들은 내장지방을 형성하고 내장지방이 위와 같은 원리로 기능부전에 쌓이게 된다.
				- 결국 전신 인슐린 저항증이 생긴다. -> 대사증후군, 지방간, 당뇨병, 심장질환 발병
		- 유전과 노화도 지방축적에 영향을 준다
			- 지방조직이 늘어나도 '숫자'와 '크기'가 같이 늘어나면 지방 대사 기능 부전이나 인슐린 저항성으로 이어지는 위험성이 낮다.
				- 숫자나 크기 둘 중 하나가 이루지지 않는다면 문제가 발생한다.
			- 당뇨병 가족력을 가진 사람들은 체중이 늘어날때 지방분화가 잘 이루어지지 않는 ' 비대성 비만'이 될 가능성이 있다.
			- 유전적 소인으로 인해 지방세포의 분화가 잘 이루어지지 않으면 체중이 많이 나가지 않아도 인슐린 저항성이 먼저 생길 수 있다.

			- 소아청소년기에는 '증식성 비만'으로 이어질 수 있다.
				- 소아청소년기에 비만하더라도 성인이 되어 더 이상 체중이 늘지 않게 관리하면 당뇨병이나 심혈관질환으로 이어지는 위험은 높지 않았다.
				- 소아청소년기에 마른 몸매를 갖고 있다가 성인이 되어 비만해진 경우에는 고혈압, 당뇨병, 심혈관질환 발병 위험이 훨씬 높아졌다.
			- 성인기에는 '비대성 비만'으로 이어질 수 있다.
				- 나이가 들수록 지방세포의 분화가 잘 안된다.
				- 노화로 지방세포 교체 주기가 길어지다 보니 비대성 지방세포가 많아지면서 만성염증과 인슐린 저항성으로 이어지기 쉽다.
				- 나이가 들수록 체중보다는 허리둘레 관리에 더 신경을 써야 한다.
		- 피하지방조직의 확장성
			- 피하지방은 한없이 늘어나지 않는다.
			- 잉여에너지를 피하지방에 저장할 수 있는 용량은 한계가 있다.
			- 우리 몸의 피하지방은 스펀지에 비유하면 이해하기 쉽다
				- 스펀지가 물을 한계치 이상 빨아들이면 더 이상 물을 머금고 있지 못하듯이 피하지방도 마찬가지다.
				- 넘치는 피하지방은 다른조직으로 흘러들어가 저장된다.
				- 그것이 사람의 몸에 복합적인 문제를 일으킨다.
			- 뚱뚱한 사람들은 피하지방에 많은 지방을 비축하고 있음에도 불구하고 필요할 때 제대로 끄집어내 쓰지 못한다.
			- 날씬하고 근육량이 많은 사람들은 식사로 들어오는 당과 지방을 근육에도 저장하고 피하지방에도 저장해 여유공간이 넘친다.
			- 날씬하지만 근육량이 없는 사람들은 저장공간에 여유가 없어 내장지방이 쌓인다.
			- 비만은 피하지방조직의 저장량이 한계에 다달아서 생기는 병이다.
			- 스트레스 호르몬인 코르티솔 역시 내장지방의 원인

					- 과당이 중성지방 합성을 증가시킴과 동시에 요산생성도 증가시켜 미토콘드리아 산화 스트레스를 유발한다.

				- 과당은 세포 내에서 일종의 '알람'시그널로 작동해서 우리몸을 위기상황에 대처하는 모드로 바꾼다.

		- 12시간 이상 공복을 했음에도 인슐린 수치와 공복혈당이 높다면 인슐린 기능이 떨어져 있다는 것
			- 이런 경우 단순히 탄수화물 섭취량을 줄이는 것만으로는 부족하다.
		- **인슐린 호르몬이 보다 확실하게 휴식을 취할 수 있도록 '의도적으로' 굶어주어야 인슐린 저항성이 개선된다.**
		- 아에 먹지 않으면 상황이 달라진다.
			- 우리는 잠을 자는 동안 내 몸은 손상된 부분을 수리하고 부족한 것을 보충한다.
		- 마지막 식사 후 12시간 경과 -> 간에 비축된 글리코겐 저하 -> 배고픔 신호 -> 인슐린 수치 저하 -> 피하지방을 유리지방산 형태로 꺼내 사용
		- 공복상태가 길어질수록 유리지방산을 소비
		- 간에서는 지방산을 분해해 케톤을 생성
			- 케톤은 단식 기간 중 뇌와 근육의 에너지원이 될 뿐 아니라 식욕을 늘려주는 효과도 있다.
			- 공복 상태에서는 인슐린이 휴식을 취하는 대신 글루카곤(글리코겐 분해 및 당신생합성 자극), 성장 호르몬(지방 분해 촉진), 코르티솔, 아드레날린 등의 활성물질이 혈당 저하를 막아준다
		- 단순히 섭취칼로리를 줄이는 저칼로리 다이어트에서는 근손실을 피할 수 없다.
		- 단식을 적절히 활용하면 체지방을 줄이면서 근육손실을 최소화 할 수 있다.
			- 인슐린 저항성이 있다면 탄수화물 섭취량을 줄이는 것도 필요하지만 스펀지를 짜듯 공복 시간을 더 길게 가져서 근육과 지방세포 내에 쌓인 지방을 에너지원으로 쓰게 해야한다.
		- 간헐적 단식의 결과
			- 체중감소
			- 인슐린 저항성 및 렙틴 저항성 개선
			- 만성염증 및 산화스트레스로 인한 단백질, 지질, DNA에 대한 손상 감소
			- 면연력 강화
			- 기초 대사량 증가
			- 노르에피네프린 증가
			- 성장 호르몬 증가
				- 성인 남성 48시간 단식 -> 성장호르몬 5배 증가
				- 지방 분해 촉진 효과
				- 골격근 생성에 영향
			- 글루카곤 증가
			- 자가포식
				- 산화 스트레스, 만성염증 감소
				- 미토콘드리아 기능 활발 -> DNA 손상 방어 -> 암 예방
		- 간헐적 단식이 대사 유연성을 개선하는 가장 확실한 치료법
			- 지속적인 저칼로리 다이어트는 대사 유연성을 개선하는데 큰 도움을 주지 못한다.
				- 안정시 대사율 저하를 피할 수 없기 때문
		- 격일 단식도 마찬가지의 결과
			- 안정시 대사율 변화 없음
		- 잘 챙겨 먹다가 간헐적으로 단식하면 몸이 눈치채지 못한다.
			- 안정시 대사율은 그대로 유지된 채 비축된 지방을 쓰게 되므로 자연스럽게 대사가 유연해진다.
		- **간헐적 단식의 필수조건**
			- 14시간 넘게 단식하고 10시간 동안 잘 챙겨 먹을 것
				- 24시간 공복이 가장 가성비가 좋다 (오후 6시에 저녁식사가 끝났다면 다음날 오후 6시까지는 물만 마실 것)
			- 먹어야 하는 날은 잘 챙겨 먹을 것 (먹는 양을 제한 하지 않음)
				- 부실하게 먹으면 저칼로리식단과 다를게 없어진다.
				- 몸에 좋은 음식을 챙겨 먹는것이 효율적
				- 영양소를 충분히 섭취 할 수 있는가를 따져볼 것
					- 하루에 3~4회 걸쳐 단백질 섭취를 반드시 해야 한다.
			- 술과 과당을 일정 기간 끊을 것
			- 서카디안 리듬 회복
				- 장내 미생물 불균형 개선 -> 지방간 개선
		- 24시간 단식이 가장 가성비가 좋다
		- 단식보다 잘 챙겨 먹는게 더 중요하다
			- **먹어야 하는 날 잘 챙겨 먹어야 안정시 대사율을 유지할 수 있으므로 칼로리를 계산하지 말고 배불리 잘 먹어야 한다.**
	- ### 3장
		- 운동은 최고의 명약
		- 규칙적인 운동이 가져오는 효과
			- 체지방 허리둘레 감소
			- 심폐지구력 강화
			- 근육량 근력 유지 및 향상
			- 혈압, 혈당, 중성지방, 콜레스테롤 수치 감소
			- 인슐린 저항성, 렙틴저항성 개선
			- 지방간 개선
			- 치매 예방
		- 운동 효과가 누적될려면 적어도 48시간 이내에 운동 할 것
			- 주 4회 이상
		- 운동과 호르메시스
			- 운동을 하면 다양한 스트레스가 발생하는데 이러한 스트레스가 세포 내에서 신호 경로를 활성화 하고 골격근에는 생리 활성 물질을 분비하여 유전자 발현 적응반응 대사조절등을 촉진한다.
		- 간헐적 단식 + 운동 의 병행이 가장 좋다
		- 운동을 하면 지방을 잘 쓰는 몸으로 바뀐다
			- 유산소 운동을 하면 심폐지구력과 근골격계의 적응반응이 향상된다
			- 무산소 운동을 하면 인슐린 자극이 없이도 골격근이 포도당으로 유입해서 에너지원으로 이용한다.
		- 근력운동
			- 근원 섬유가 많아질 수록 근육 세포의 사이즈가 증가한다.
				- 근육량 증가와 무관하게 근육의 대사 기능이 개선된다는 소리
			- 근육량이 늘어나면 안정시 대사율이 증가한다
				- 근력 운동만으로도 내장지방을 줄일 수 있다.
				- 잘 챙겨먹는 식이 요법이 반드시 병행 되어야 한다.
				- 당 대사에 유리하다.
		- 유산소운동
			- 미토콘드리아 숫자가 증가하고 효율이 좋아진다.
			- PGC-1a 발현이 빠르게 증가
				- 미토콘드리아 단백질 발현을 조절 하는 전사 조절 도움인자로 작용
				- 활성 산소 감소
				- GLUT4 단백질 발현 증가 (골격근 인슐린 감수성 증가)
		- 고강도 인터벌 훈련이 가장 좋다
			- 숨이 턱에 찰 정도의 자극으로 1~2분 이후 중간에 회복시간을 주면서 3~7회 반복
			- 시간 보다 강도가 중요
			- HOW TO 고강도 인터벌 운동
				- 고정식 자전거
					- 30초간 턱에 찰정도로 페달을 가능한 빠르게 힘들게 밟는다.
					- 이후 2~4분간 페달을 천천히 밟으면서 숨이 돌아오길 기다린다.
					- 또다시 30초간 페달을 빠르고 힘들게 밟는다.
					- 다시 2~4분간 페달을 천천히 밟으면서 숨이 돌아오길 기다린다.
					- 이것을 15~30분 반복한다.
				- 트레드밀
					- 5분 정도 워밍업으로 시속 5~6km로 걷는다.
					- 30~60초를 시속 8~12km로 숨이 턱에 찰 정도의 강도로 빠르게 뛴다.
					- 그리고 나서 1~3분간 시속 5km로 걷는다.
					- 이것을 10~20분 동안 반복한다
				- 계단 오르기
					- 5~15층을 가급적 빠른 속도로 걸어 올라간다.
					- 숨이 턱까지 차면 천천히 걸어 내려 오거나 엘리베이터를 타고 내려온다.
					- 숨이 돌아오면 다시 계단을 빠른 속도로 걸어 올라간다.
					- 이것을 15~30분 반복한다.
	- ### 4장
		- 의자중독에서 벗어나기
		- 흡연만큼 해롭다
		- 꼼작 않고 오래 앉아 있는 것은 수명을 단축시키고 흡연만큼이나 건강에 헤롭다는 것이 정설이다.
		- 강도 높은 운동을 해도 앉아 있는 시간이 길어 지면 운동의 효과가 상쇄
		- 꼼짝 않는 시간이 1시간 길어질수록 허리 둘레와 중성지방 등의 수치가 올라간다.
		- 결국 하루 30분 운동하는 것보다는 얼마나 많이 움직였는지가 더 중요하다.
		- 하루 2.5 시간 서있게 하거나 30분 마다 가볍게 걷게 해도 규칙적으로 운동하는 것보다 24시간 혈당과 인슐린 수치를 낮추어 인슐린 민감성을 개선시켰다.
			- 하루 8시간 이상 오래 앉아 있으면 운동의 효과가 상쇄된다.
			- 30분에 한 번씩은 자리에서 일어나야 한다.
			- 그게 어렵다면 적어도 1시간마다 일부러 일어나서 스트레칭을 하거나 5분 정도 가볍게 걸어주어야 한다.
	- ### 5장
		- 일시적으로 술과 과당을 끊어라
		- 지방간은 인슐린 저항성을 초래하면서 신진대사를 서서히 망가뜨린다.
		- 술, 설탕, 과일, 과일주스, 청량음료를 아에 입에 대지 않는 것보다 확실한 치료법은 없다
		- 내 간을 망가뜨린 원인은 칼로리 과잉이 아니라 술과 과당의 지나친 섭취 때문이다.
		- 간은 회복력이 빠른 장기다. 한달간 확실하게 끊어서 지방간을 치료한 다음 이후부터 평소보다 조금식 먹을 것
		- 마른 지방간 환자는 체지방률을 낮춰야한다.
			- 내장 지방을 줄이고 근육량을 늘리는게 하나의 치료 방법
			- 탄수화물 섭취를 줄이고 단백질을 매끼 잘 챙겨 먹으면서 운동해야한다.
			- 질 좋은 수면은 근육 생성에도 도움이 될 뿐 아니라 렙틴 수치도 개선해준다
	- ### 6장
		- 서카디안 리듬을 회복하자
		- 마스터 생체시계라고 이해하자
			- 눈을 통해 들어오는 빛의 자극으로 밤과 낮을 구분
			- 호르몬, 자율 신경계를 통해 말초시계를 싱크로나이즈(같은 시간에 작동하게 하는 것)한다.
				- 음식 섭취나 수면 각성 신체활동 등을 통해 나타나는 우리 몸의 생리적 반응
		- 인슐린에 휴식을 주지 않으면 서카디안 리듬이 무너진다.
		- 인슐린은 낮 시간에 왕성하게 활동하는 호르몬
			- 밤에는 수면 호르몬인 멜라토닌에게 자리를 내어준다
			- 멜라토닌이 췌장의 베타세포의 회복에 중요한 역할을 한다.
		- 취짐 3~4시간 전에 식사를 끝내야 한다.
		- 서카디안 리듬을 되돌리는 생활 습관
			- 먹으면 안되는 시간에 배고픔이 온다면 물을 양 것 마셔서 달랜다.
			- 그럼에도 불가하다면 오이, 당근, 브로콜리, 양배추, 연두부로 달랠것
			- 가급적 탄수화물은 금할 것
			- 혈당이 많이 올라간 상태로 잠드는 것은 인슐린 호르몬과 간에 부담을 준다
			- 일어나자 마자 식사를 하는 것 보다는 1시간 정도 지나서 하는 것이 좋다.
			- 서카디안 리듬에서 12시간 공복 유지는 필요 충분 조건
		- 식단
			- 식이 섬유와 단백질, 복합 당질로 구성
				- 퀴노아죽, 오트밀, 샐러드, 플레인 요거트, 베리류과일, 견과류
				- 부족한 단백질은 셰이크 형태로 섭취
			- 순서
				- 아침에는 채소와 단백질
				- 이후에는 탄수화물 음식을 먹을것
		- 수면의 질이 중요하다
			- 서카디안 리듬 회복에서 가장 중요한 것은 수면의 양과 질
				- 하루 6시간 미만의 짧은 수면은 인슐린 저항성, 비만, 고혈압, 당뇨병, 심혈관질환 발생 위험을 높임
			- 적어도 7시간 이상 수면을 취할 것
				- 특히 첫 수면 4시간이 가장 중요
			- 규칙적인 시간에 자고 일어나기
			- 햇빛을 활용
				- 세로토닌 생성 증가
			- 카페인과 술을 멀리할 것
			- 침실 공간을 수면 모드 공간으로 바꾸기
				- 실내 온도는 약간 선선하게 유지
				- 최대한 어둡게 만들기
			- 잠들기 2시간 전부터 블루라이트 차단
			- 낮잠 활용
				- 20분 정도 적당 30분 넘기지 말 것
			- 위장을 편안하게 만들 것
				- 저녁에 과식하지 말 것
			- 부교감 신경을 활성화 할 것
				- 스트레스를 받으면 교감 신경이 항진된다 -> 교감신경이 항진되면 잠에 들기 힘들다
				- 명상을 하거나 가벼운 음악감상으로 마음을 달랠 것
				- 미지근한 물로 샤워
				- 가볍게 스트레칭
			- 규칙적으로 운동한다.
				- 이른 아침에 유산소
				- 저녁식사전에 근력 운동
					- 잠자리 들기전 과한 운동은 교감신경을 자극 -> 숙면 방해
				- 저녁식사 후에는 가볍게 걷기
			- 숙면에 대한 강박에서 벗어날 것
				- 잠자리 2~3시간 전 다음 날 해야 할 일들을 기록 해보자
			- 숙면에 도움이 되는 식품이나 영양 보충제의 도움을 받을 것
				- 따뜻한 우유 한 잔
				- 멜라토닌 복용
					- 취침 30분전
				- 마그네슘 복용

			- 체중과 체지방이 지속적으로 빠지려면 안정시 대사율을 잘 유지해야 한다.
			- 간헐적 단식과 운동으로 다이어틀 진행하고 난 뒤에 지속적이고 규치적인 유지가 쉽지 않다.
			- 차라리 인슐린저항증을 개선한 뒤 잘 챙겨 먹으면서 더 많이 움직이는 것이 났다.
			- 이후 안정시 대사율이 자리를 잡으면 다시 간헐적 단식과 운동을 병행 할 것
		- 왜 단백질 셰이크인가?
			- 탄수화물 제한 다이어트를 할 때 근육 손실을 최소화 할려면 단백질 섭취량을 평소보다 많이 먹어야 한다.
			- 단백질이 포함된 아침식사를 할 경우 근육생성이 시작되고 시간이 지나면서 혈중 아미노산이 낮아지면서 근육분해가 시작된다.
				- 근육 운동을 병행하면 근육생성이 강화되면서 공복 시 근육 분해 시간이 줄어든다.
				- 근육 운동 후 20g정도 단백질을 섭취했을 때 가장 근육생성이 크게 자극 받는다.
			- 노인들은 근육 생성을 자극하기 위해 더 많은 양의 단백질을 섭취해야 한다.
			- 단백질을 3시간마다 하루 4번 섭취할 때 근육생성 효과가 가장 컸다.
			- 공복 14시간을 제외한 나머지 시간 동안 하루 4번 단백질을 섭취하게 한다.
			- 아침에 단백질을 잘 챙겨 먹는 것은 혈당 조절면에서도 효과적이다.
				- 빵이나 과일로 하루를 시작하면 점심식사후 혈당이 더 높게 올라가고 잘 떨어지지 않는다.
