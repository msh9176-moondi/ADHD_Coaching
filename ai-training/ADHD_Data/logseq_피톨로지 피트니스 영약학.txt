- # 영양의 이해
	- ## 1. 영양과 항상성
		- ### 1. 항상성
			- 환경에 적합한 생명 활동을 할 수 있도록 유지 보수하여 항상 일정한 상태를 항상 유지 할려는 성질
			- 뇌가 신경계를 구성하여 내분비계를 통솔하는 방식으로 우리 몸의 곳곳에 일어나는 작은 일들까지 모두 조절해 항상성을 유지한다.
			- 항상성이 잘 유지되기 위한 조건
				- 세포가 일을 해야함
				- 세포가 일을 하기 위해서는 에너지의 꾸준한 공급이 필요
		- ### 2. 우리몸의 항상성
			- 체온을 유지하는 것도 항상성
				- 체온의 상승 -> 혈관 확장 -> 혈액의 피부 이동 -> 땀 발생 -> 피부 표면의 열을 발산 -> 체온 하락
				- 체온의 하락 -> 혈관 수축 -> 근육의 떨림 -> 진동으로 인한 열 발생 -> 체온 상승
			- 체중을 유지하는것도 항상성
				- 체중을 유지하기 위해 먹고 움직임
			- 생명현상을 유지하는데 가장 중요한 첫번째는 호흡
			- 생명현상을 유지하는데 중요한 두번째는 먹는 것
				- 인간은 생존을 위해 진화 -> 기근에 대비하는 능력의 상승 -> 에너지 물질 저장능력 상승 -> 체지방의 유연한 조절 능력 발생
			- 항상성은 생명유지에 더 긴급하고 직접적인 지표일수록 적극적으로 조절함
			- 갑작스런 다이어트 -> 스트레스 발생 -> 뇌의 생존 스위치 ON -> 식욕 증가
				- 다이어트로 인해 먹는 양이 현저히 적어지면 부족한 칼로리를 얻기 위해 몸에 저장된 에너지를 사용하여 체중이 줄 거 같지만 실제로는 저장된 에너지를 끌어다 쓰거나 에너지의 소비를 줄이려고 하다 보니 기초대사량의 감소로 이어짐
			- 몸은 체중의 항상성을 지키기 위해 섭취하는 에너지 감소에 맞춰 열에너지 방출을 줄여나가는것
			- 다이어트는 뇌의 생존 스위치를 켜지 않는 선에서 음식 섭취량을 서서히 줄여나가야 한다.
		- ### 3. 항상성이 깨진다면
			- 우리 몸의 항상성 기전은 외부/내부로부터의 자극에서 시작된다.
			- 바이러스로 인한 자극
				- 반사 반응 (기침 등)
				- 1차 면역 반응 (백혈구, 대식세포, NK 세포 등)
				- 2차 면역 반응 (B-림프구, T-림프구 등)
			- 만약 항상성 기전이 깨져서 우리 몸이 원래의 상태로 돌아오지 않는다면 그것을 **질병**이라고 부른다.
			- 치료의 기본은 여러가지 자극에 의해 깨진 항상성을 원래의 상태로 돌려놓는 것
	- ## 2. 영양소의 소화와 흡수
		- 섭취한 음식물의 3가지 경로
			- 소화 흡수되어 에너지로 사용되고 필요에 의해 저장
			- 소화 흡수되어 사용되고 나머지는 소변을 통해 버려짐
			- 소화 흡수되지 못하고 대변으로 배설
		- ### 1. 소화
			- 탄수화물, 단백질, 지방 모두 그대로 사용 불가
			- 소화 기관을 통해 일련의 과정을 거처 흡수할 수 있는 크기로 작게 만들어야 한다.
				- 탄수화물 -> 포도당 & 과당
				- 단백질 -> 아미노산
				- 지방 -> 지방산 & 글리세롤
			- 소화의 형태
				- 물리적 소화 -입, 위장, 소장, 대장
					- 음식물을 작은 조각으로 만들어 액체로 변환
				- 화확적 소화 - 침샘, 간, 췌장에서 분비하는 소화효소
					- 액체로 변환된 음식속에 있는 영양소를 흡수할 수 있는 가장 작은 분자 형태로 만듬
				- 미생물에 의한 소화
					- 발효
			- 소화 과정에 물이 반드시 필요
				- 하루 평균 9~10L 필요
			- 구강 및 식도
				- 침에는 소화효소 함유
					- 아밀레이스 -> 은은한 단맛 유발 -> 혈당 증가 -> 인슐린 분비 -> 포만감
			- 위장
				- 위장안에 음식물이 들어옴 -> 부교감 신경 촉진 -> 단백질 소화 발생
			- 소장
				- 소장에서 나오는 소화효소는 3대 영양소를 모두 소화함
			- 대장
				- 세균성 소화가 진행
				- 일부 올리고당이나 식이 섬유는 유익균의 먹이로 이용 병원균을 억제하여 장내 환경에 긍정적인 영향을 줌
		- ### 2. 흡수
			- 수동수송
				- 누가 떠밀어 주는 힘에 의해 이동을 말함
				- 농도차가 대표적인 예 - 확산
					- 고농도에서 저농도로
					- 높은 위치에서 낮은 위치로
					- 뜨거운 곳에서 낮은 곳으로
					- 에너지가 많은 곳에서 적은 곳으로
			- 영양소가 몸안으로 흡수되려면 세포막을 통과해야 함
				- 세포막은 지질로 구성
					- 지방을 비롯한 지용성 물질과 산소, 이산화탄소는 쉽게 통과 가능
					- 반대로 포도당 과당 아미노산같은 이온들은 수용성이기에 세포막 통과 불가
						- 이를 해결하기 위해 단백질을 이용한 촉진확산 사용
			- 능동수송
				- 화확적인 균형을 거스르며 특정 물질들을 이동시킴
				- 운반체의 수가 한정적 -> 영양소들이 세포 내로 흡수되기 위해 경쟁 발생 (경쟁적 억제)
					- 포도당이나 아미노산, 이온이 이 방식으로 흡수되는 경우가 많음
			- 탄수화물의 흡수
				- 단당류의 형태로만 흡수가 진행
					- 포도당
						- 능동수동으로 인해 에너지를 써서라도 모두 흡수됨
						- 소장에서 나트륨의 재흡수를 이용해서 나트륨과 포도당이 같이 흡수됨
					- 과당
						- 농도차이에 의해 흡수되기에 한계가 있음
						- 한계이상의 과당은 흡수되지 못하고 대장으로 이동
						- 대장으로 이동한 과당은 지방산과 가스를 만듬
						- 장내 운동성을 변화시켜 과민성장증후군 유발의 원인이 됨
			- 단백질의 흡수
				- 펩타이드 운반체
					- 단백질을 아미노산으로 분해 -> 모세혈관으로 이동
				- 아미노산 운반체
					- 아미노산을 3가지로 분류하여 흡수
					- 수송체 개수가 한정적 -> 경쟁 발생
					- 아미노산 보충제가 오히려 과도한 경쟁을 발생시켜 흡수 효율을 떨어뜨림
				- 탄수화물과는 반대로 단백질은 분해된 것이 오히려 흡수가 잘 안됨
			- 지방의 흡수
				- 지방이 분해 되어 흡수 될려면 물과 섞여야 함
				- 하지만 지방은 물과 섞일 수 없음
				- 췌장의 유화작용을 통해 지방이 물과 섞일 수 있는 구조로 바뀜 -> 모세혈관으로 이동
- # 영양소
	- ## 탄수화물
		- 우리 몸에서 반드시 필요로 하는 영양소 중 하나.
			- 포도당이라고 하는 가장 기초적인 영양소를 얻으며, 우리 몸은 이 포도당을 가장 기본적인 에너지원으로 사용한다.
			- 인체를 구성하는 물질은 탄소를 중심으로 결합
			- 탄소를 중심으로 결합하는 물질 = 유기물
				- 탄소 + 물 = 탄수화물
		- 탄수화물의 기능
			- 최우선적인 에너지원
			- 탄수화물의 최소 단위 = 포도당
			- 우리몸을 구성하는 대부분의 세포는 포도당을 최우선적인 에너지원으로 사용
			- 포도당 부족 -> 당신생 (포도당을 만들기 위해 다른 영양소를 끌어다 쓰거나 탄수화물 식품을 먹도록 식욕을 증가시키는 등 할 수 있는 모든 수단 동원)
			- 포도당 주요 저장소 (글리코겐 형태로 저장)
				- 간
				- 근육
			- 포도당 1개
				- 유산소 대사 -> ATP 32~38개 생성
				- 무산소 대사 -> ATP 2개
		- 에너지원으로 단백질의 이용 방지
			- 며칠 이상 단식 OR 과격한 운동 장시간 -> 글리코겐 감소(포도당 감소) -> 혈당 부족 -> 단백질 분해 -> 아미노산 -> 포도당 -> 근손실
			- 체중 조절 등을 위해 탄수화물을 먹지 않고 단백질만 먹는 식습관은 포도당과 단백질을 적절히 섭취하는것보다 비효율적
				- 탄수화물을 섭취하지 않고 단백질만 먹는다 -> 근손실
		- 리보스 (단당류)
			- DNA, RNA 등 유전물질의 원료
			- 포도당이 부족 할 경우 세포분열에 지장
		- 탄수화물의 종류
			- 단당류
				- 포도당
					- 모든 탄수화물의 가장 기초적인 물질
				- 과당
					- 대부분 간으로 흡수되어 지방을 합성하는데 사용
					- 과한 과당 -> 인슐린저항증 증가
					- 인간이 과당을 태워서 에너지로 사용하는 능력은 극히 제한적
				- 뇌당
			- 이당류
				- 설탕
					- 단당류 + 포도당
					- 천연당
					- 가장 순수한 탄수화물 덩어리
				- 유당
					- 포도당 + 갈락토스
					- 영아의 성장 발달에 꼭 필요한 물질
				- 맥아당
					- 포도당 + 포도당
			- 올리고당류
				- 대부분의 올리고당은 소화 불가
				- 이용성 비효율
				- 주로 대장에서 대장 내 균의 먹이로 사용
				- 일부 올리고당의 경우 장내 유익균의 먹이로 사용
					- 프리바오틱스
					- 이소말토올리고당
					- 프럭토올리고당
				- 과량 섭취할 경우 과민성장증후군 유발
			- 다당류
				- 전분
					- 식물이 포도당을 저장하는 대표적인 형태
					- 아밀로스와 아밀로펙틴 두가지로 분류
				- 글리코겐
					- 동물이 포도당을 저장하는 대표적인 형태
				- 식이섬유
					- 섬유질
					- 주로 과일, 채소, 곡류, 뿌리식물에 풍부하게 함유
					- 소화가 잘 안됨
					- 장 운동 촉진 -> 변 형성
			- 탄수화물의 대사
				- 탄수화물 -> 포도당, 과당 -> 소장 -> 흡수 -> 모세혈관 -> 간 OR 근육
				- 간
					- 포도당 합성 비효율 (저장 탱크 공간 부적합)
					- 과당이 주로 저장됨
						- 저장탱크가 작기 때문에 지방으로 저장 -> 지방간
				- 근육
					- 포도당 합성 효율 (저장 탱크 공간 적합)
				- 포도당을 혈액에서 제거하는 가장 큰 역할을 하는것은 췌장에서 분비된 인슐린과 근육, 지방조직
				- 실제 혈당의 항상성 유지 역할은 간
				- 각 세포로 유입된 포도당은 생명활동 에너지를 제공
					- 포도당이 ATP로 바뀌는 방식 - (아데노신 + 인산 2개) + 인산 = APT
						- 포도당(탄소 6개) -> 탄소 3개, 피부르산 2개
							- 산소 이용 가능 (유산소성 대사) -> 구연산 회로 (TCA Cycle) -> ATP(포도당 1개당 32~38개 생성) = 에너지의 효율적인 사용
								- 피부르산 -> 미토콘드리아(구연산 회로) -> 활성 아세트산 (Acetly - CoA) 합성 -> 구연산 회로(TCA Cycle) -> 구연산 합성 -> 수소이온 -> 전자전달계 -> 산화적 인산화 -> ATP 합성
							- 산소 이용 불가 (무산소성 대사) -> 젖산 대사 -> ATP (포도당 1개당 2개 생성) = 에너지의 비효율적인 사용
								- 피부르산 -> 세포질 -> 젖산 -> ATP
				- 뇌는 포도당을 위주로 사용면서도 포도당을 저장하는 능력이 없어 혈당에 100%의존
					- 안정적인 혈당의 항상성 유지는 필수
					- 뇌가 필요로 하는 포도당 130g
					- 뇌는 수면중에도 포도당을 계속 소비
						- 혈당이 부족하거나 인슐린 저항성이 있다면, 수면 중 뇌세포 재생/청소/성장도 어려워짐
						- ## 🧠 수면 중 뇌는 뭘 하냐면:
						- ### 수면 중 뇌의 주요 활동들:
						    
						  | 과정 | 설명 |
						  |---|---|
						  | 🧽 **뇌청소 (글림프 시스템)** | 낮 동안 쌓인 노폐물, 아밀로이드 제거 |
						  | 🧬 **신경세포 회복 & 성장** | 손상된 뉴런 회복, 시냅스 리모델링 |
						  | 🌱 **기억 고착화** | 학습 정보 정리 → 장기 기억으로 전환 |
						  | 🧘 **감정 재조정** | 감정 경험 재처리 → 스트레스 해소 효과 |
						- ## 📌 이 모든 과정엔  **ATP가 대량으로 필요**
						    
						  수면 중이라고 해서 에너지를 안 쓰는 게 아니라  
						    
						  **오히려 뇌는 낮보다 더 집중적으로 회복 작업을 진행**  
						    
						  그리고 이때의 에너지원이 바로 **포도당**  
						    
						  (케톤도 어느 정도는 사용 가능하지만, 포도당이 메인)  
						-
						- ## **당이 불안정하거나 인슐린 저항성이 있으면...**
						- ### 어떤 일이 벌어질까?
						    
						  | 영향 항목 | 결과 |
						  |---|---|
						  | ❌ 포도당 대사 효율↓ | 뇌세포 재생 속도 저하 |
						  | ❌ ATP 부족 | 시냅스 리모델링 지연, 기억 고착 실패 |
						  | ❌ 글림프 시스템 저하 | 노폐물 제거 부족 → 아밀로이드 축적 ↑ |
						  | ❌ BDNF↓ | 신경가소성 저하 → 뇌 성장, 회복력 ↓ |
						  | ❌ 도파민 생성↓ | 감정 재처리 능력 약화 → 불안감, ADHD 증상 심화 |
						- 수면 중 **저혈당 상태** → **해마 기능 저하**
						- **인슐린 저항성** 있는 사람은 렘수면의 **질이 낮고, 기억력 저하** 경향
						- BDNF 수치와 수면의 질 + 포도당 대사가 **강하게 연결되어 있음**
						- ## 핵심 요약
						    
						  | 조건 | 뇌세포 회복 상태 |
						  |---|---|
						  | ✅ 안정된 혈당 & 인슐린 감수성 | 활발한 뇌세포 재생, BDNF↑, 집중력↑ |
						  | ❌ 혈당 불안정 or 인슐린 저항성 | 재생 저하, 기억력↓, 감정조절↓, ADHD 증상↑ |
			- 혈당 부족시 정상적인 기능 유지에 문제가 생김
				- 무산소 운동을 해서 근육 내 글리코겐 저장고를 늘릴것
					- 근육량 증가 -> 글리코겐 저장소 확장 -> 혈당 안정
				- 유산소 운동
					- 근내 지방과 미토콘드리아 증가
					- 혈중 지방산 농도 감소
			- 급격한 혈당 상승은 인슐린 분비의 급증을 유발 -> 저혈당 -> 배고픔 -> 식욕 상승 -> 비만
			- 식품섭취 -> 포도당 흡수 -> 혈당 증가 -> 췌장에서 인슐린 분비 -> 근육/지방조직으로 이동 -> 지방세포에서 렙틴 분비 -> 렙틴이 간괴 시상하부 수용체에 결합 -> 포만감 유발
			-
			- 식품섭취 -> 과당 흡수 -> 일부 포도당으로 변화 되거나 충분시 간으로 이동 -> 글리코겐 or 지방간 합성 -> 과량의 과당 -> 지방간 -> 인슐린/렙틴의 연속작용 나타나지 않음
	- ## 단백질
		- 단백질의 정의
			- 우리 몸에서 생명 활동을 위한 필요한 효소, 호르몬, 면역물질 등 다양한 조절 물질과 뼈, 근육, 힘줄, 인대, 연골, 피부 및 모발 등 다양한 구조 물질의 합성을 담당하고 있는 열량 영양소이다. (에너지원으로서의 기능은 작다)
			- 탄소 + 수소 + 산소 + 질소
		- 단백질의 기능
			- 체내의 다양한 대사 반응은 단백질에 의해서 일어남
				- 뇌의 조절 명령을 전달하는 호르몬이나 신경계는 표적기관에서 특정 단백질을 합성하여 작용하게 함
				- 인슐린, 성장호르몬, 아민 호르몬을 합성
					- 카테콜아민 : 티로신으로 부터 합성되는 신경전달물질 -> 도파민, 아드레날린, 노르아드레날린이 해당
					- 아민 : 신경계에 작용하는 강한 생리활성물질, 아드레날린, 도파민, 히스타민, 세로토닌, 티라민
			- APT라는 에너지를 만드는 대사에 참여 가능
				- 류신, 라이신을 제외한 아미노산은 포도당으로 분해가능
				- 류신, 라이신은 케톤과 같은 대사 경로로 이용
		- 단백질의 구조
			- 아미노산
				- 20가지 아미노산에 의해 단백질이 합성
			- 펩타이드
				- 아미노산 + 아미노산
			- 단백질
				- 아미노산 30~10000개 이상 결합
				- 결합이 커질수록 새로운 성질이나 기능이 생김
			- 아미노산의 종류
				- 체내 합성 가능  -> 비필수
					- 류신
					- 이소류신
					- 라이신
					- 발린
					- 페닐알라딘
					- 트레오닌
					- 트립토판
					- 메티오닌
					- 히스티딘
				- 체내 합성 불가능 -> 필수
					- 알라닌
					- 아스파르트산
					- 아스파라긴 시스테인
					- 글루탐산
					- 글리신
					- 프롤린
					- 하이드록시 프롤린
					- 세린
					- 티로신
					- 아르기닌
				- 광학이성질체에 따른 분류
					- L - 아미노산
						- 인체에서 단백질을 형성하는 아미노산
					- D - 아미노산
				- 아미노기 위치에 따른 분류
					- 아미노기가 몇 번째 탄소에 가서 결합해 있느냐에 따라 결정
						- 알파~오메가 순
						- 알파 - 아미노산은 모두 생체 내에서 단백질을 합성
						- B - L -  알라닌 = 지구력 증가에 사용
			- 단백질 대사
				- 하루에 인체 내에서 순환 되는 250g의 단백질중 5/6 정도는 적혈구, 백혈구, 근육, 효소, 호르몬 등의 분해에 의해 생성된 아미노산을 다시 재활용
				- 약 50g 정도가 근육 합성에 이용
				- 에너지물질 (탄수화물, 지방의 섭취)가 부족하면 섭취된 단백질도 에너지로 우선 사용
				- 에너지 필요량을 충족시킨 상태에서 단백질이 섭취되어야 그 절반이 근육합성에 이용
				- 지속적인 단백질 섭취의 관리가 중요
				- 근육합성의 신호는 그 때의 아미노산 풀의 상태에 따라 합성이 좌우
				- 한번에 많이 먹는 것보다 주기적인 섭취를 통해 농도를 최적화 상태로 유지
					- 단백질 섭취에 따른 혈중 아미노산 그래프는 큰 의미가 없음
					- 주기적인 식사 섭취를 통해 아미노산 풀의 일정 농도를 유지 -> 근합성
				- 소화 흡수가 빠른 단백질을 너무 많이 섭취 -> 당신생 기능성 증가 -> 지방 합성
			- 단백질 합성
				- 유전에 의해 결정
					- DNA 내 필요한 유전정보를 RNA가 전달  -> 리보솜 -> tRNA가 정보에 맞는 아미노산을 가져와 단백질을 합성
					- mRNA(DNA에 있는 정보 운반) -> 리보솜 에서 단백질 합성 <- tRNA(아미노산 운반)
				- 단백질 합성시 부족한 아미노산이 있을경우 골격근을 분해해서 부족한 아미노산을 채움 -> 근손실
					- BCAA OR 류신을 챙겨 먹어도 오히려 근손실이 일어날 수 있음
			- 단백질 에너지 사용
				- 에너지가 필요할 때 탄수화물로 포도당이 공급되지 못하면 단백질을 이용해서 포도당으로 만들어 에너지 물질을 공급하게 됨
				- 인체에서 아미노산이 분해되어 나온 암모니아는 요소의 형태로, 퓨린에서는 요산의 형태로 배출
				- 혈중 요산 농도가 증가하는 경우 -> 통풍, 신결석
					- 강한 육체 노동 혹은 화상등으로 다량의 핵산이 파괴되어 퓨린물질에 노출
					- 신장 기능 이상으로 요산의 배설 장애가 있을 때
					- 스트레스로 조직 손상을 받을 때
					- 간의 기능이 좋지 않을 때
					- 과당이나 알코올의 과량 섭취
			- 단백질 섭취 방법
				- 편식 할 경우 아미노산의 불균형을 초래
				- 식물성 보단 동물성 단백질이 완전 단백질로서 기능
	- ## 지방
		- 지방의 정의
			- 우리 몸의 에너지원이자 가장 큰 에너지 저장고
			- 인체에 들어오는 모든 에너지원은 과잉 시 지방으로 저장되어 비만을 유발
				- 포화지방, 콜레스테롤은 비반의 주범이 결코 아니다
			- 현대사회에서 지방이 문제가 된 이유는 너무 많이 먹어서 이고 결코 지방자 체에 문제가 있는 것은 아니다
				- 근내지방으로 존재해 운동 적응(유산소)에 따라 에너지의 효율적인 제공 가능
				- 외부 충격으로 부터 보호
				- 체온 유지
				- 콜레스테롤로 부터 스테로이드, 비타민 D 등을 합성
		- 지방의 기능
			- 탄소 1개  + 수소 2개
				- 더 많은 에너지 출력 가능
			- 무산소 대사에 이용 불가
		- 효율적인 에너지 저장
			- 지방은 탄수화물의 8배의 에너지를 저장
				- 수분 함량이 적어서 이러한 구조가 가능
			- 지방은 유산소 대사로만 소비됨
				- 쓰기 힘든 구조
				- 한번 살 찌면 빼기 힘듬
		- 스테로이드 호르몬 합성
			- 콜레스테롤은 스테로이드 호르몬의 원료 (부신에서 생성)
				- 테스토스테론
				- 에스트로젠
				- 알도스테론 (나트륨 조절 기능)
				- 코티솔 (스트레스에 대응)
				- 에이코사노이드 (뇌 기능 조절)
			- 기능
				- 세포막의 구성 물질
				- 성호르몬을 비롯한 스테로이드 계열 호르몬의 원료
				- 비타민 D 의 원료
			- 콜레스테롤은 활성아세트산의 연속적 결합에 의해 생성되는 물질
				- 탄수화물, 단백질, 지방이 과할 경우 지방산 OR 콜레스테롤 합성에 사용
		- 저장 방식
			- 내장지방
				- 과하면 인슐린 저항 유발
			- 피하지방
			- 근내지방
		- 트렌스지방
			- 총사망률과의 연관성을 볼 때 트랜스지방산은 되도록 적게 섭취할 것
		- 필수 지방산
			- 리놀레닉산
				- 동식물성 식품에 함유
			- 알파 리놀레닉산
				- 카놀라유, 대두유, 아마씨, 들기름
			- 필수지방산으로 에아코사노이드 대사
		- 에아코사노이드 대사
			- 비율이 중요
				- 오메가 - 6 : 오메가 - 3
				- 1~2:1 비율이 적절
		- 케톤 대사
			- 지방산의 에너지화
				- 탄수화물의 제한 (포도당을 이용할 수 없는 경우)
				- 체내 에너지 요구량 상승
	- ## 비타민
		- 비타민의 정의
			- 에너지 대사를 비롯한 다양한 몸의 기능을 조절하는 필수 물질
		- 비타민의 기능
			- 효소의 체내 작용을 보조하는 역할 (조효소)
			- 비타민 C
				- 콜라겐, 도파민, 노르에피네프린, 지방산의 에너지화 등의 합성에 필요
				- 백혈구
				- 이를 보조해주는게 글루타치온(아미노산 결합체)
			- 비타민 B
				- ATP를 만들기 위해 필요
				- B1, B2. B3. B5 필요
			- 비타민 E
				- 항상화 작용
				- 이를 보조해주는게 비타민 C
			- 비타민 D
				- 유전자 활성에 영향
				- 특정 단백질 합성에 영향
					- 칼슘결합 단백질 조절
					- 칼슘(신경전달물질)의 안정적인 작용
				- 자외선이 콜레스테롤을 비타민 D로 전환
	- ## 미네랄

			- 삼투압 조절, 신호전달, 조효소, 단백질 조절 등 인체 대사에 있어서 필수적인 기능을 하는 미량영양소

			- 삼투압 조절
				- 전해질

					- 세포내로 수분을 당겨주는 역할
				- 염소
					- 나트륨과 세포외액의 균형을 유지

					- 칼륨과 내포내액의 균형을 유지
				- 적절한 소금 섭취는 필수

				- 칼슘은 신경전달물질로 작용
				- 신경의 흥분은 신경 세포막에서 칼륨이 세포 외부로 배설
				- 나트륨과 칼슘은 세포 내부로 유입되면서 만들어낸 전위 차이에 의해 발생
			- 조효소의 역할
				- 아연, 철분, 망간, 구리
					- DNA, RNA의 합성
					- 단백질 대사
					- 항산화 반응
- # 영양 섭취
	- ## 영양학의 필요성
		- 인간의 섭취 3단계
			- 필요량을 충족시킨다
			- 식품을 양질로 구성한다
			- 생활 습관에 따라 분배를 조절한다
		- 양이 충족 -> 질로 구성 -> 타이밍에 따라 분배
			- 식사를 할 때 에너지 섭취는 줄이고 영양소, 특히 미네랄 섭취는 식사를 통해 충분하게 할 수 있도록 영양밀도를 올리고 그래도 부족할 경우 보충제를 이용하여 장기적인 영양 균형을 충족시켜야 한다.
		- 운동과 영양섭취
			- 우리 몸은 영양섭취에 대해 민감하게 반응한다
			- 갑작스런 식단 변화가 아니라 점진적으로 영양소에 대해 알아가며 스트레스를 받지 않고 실생활을 통해 습관을 만들어야할 것
			- 체중을 조절하려면 개인의 경험에 의해 일정량의 탄수화물을 섭취해보고 체중 변화를 지켜 보면서 그 섭취량을 목적에 따라 조절해 나갈 것
	- ## 영양소 섭취 기준
		- 탄수화물의 섭취
			- 일상적으로 섭취하는 탄수화물 양을 에너지 총 섭취량에서 비율로 산정
			- 60%이상일 경우 그 비율에서 나오는 운동 수행능력 체크
			- 탄수화물 단위로 5%씩 줄여가며 운동 수행능력이 유지되는지 여부 체크
			- 이러한 과정을 통해 같은 강도의 운동을 효율적으로 진행해 유산소적 적응을 할 것
			- 활동 강도가 높고 에너지 동원을 한번에 많이 해야 할 경우
				- 탄수화물의 섭취 비율을 높일 것
			- 강도는 약해도 오랫동안 지속되는 활동을 할 경우
				- 지방에 더 비중을 둘 것
		- 단백질의 섭취
			- 다양한 단백질 급원을 동원할 것
			- 운동인을 위한 단백질 섭취량
				- 체중 kg당 1.6g이 가장 최적화
		- 지방의 섭취
			- 지방은 지속적인 활동에 좋다
				- 전체 에너지 섭취의 30%까지 늘릴것
			- 지방섭취는 다이어트에 부정적인 영향을 끼치지 않음
				- 불포화 지방산 or FISH OIL만으로 식단을 구성할 경우 노화를 비롯한 질병 발생 촉진 가능
			- 운동과 지방 섭취
				- 지방은 운동시작과 동시에 사용될 수 있다.
					- 지방이 주요 에너지원으로 사용되는 경우는 글리코겐이 고갈되었을 때
			- 다이어트
				- 20%는 지방으로 구성하고 그 이하로는 줄이지 말 것
	- ## 목적별 영양 섭취 전략
		- 근력 증가와 영양 섭취
			- 무산소 운동시 근육세포 내 ATP와 이를 빠르게 보충해주는 크레아틴인산을 이용
			- 이를 인원질 시스템이라 부름
			- 체중 kg 당 필요 탄수화물
				- 근력 증가를 위해 운동
					- 주 1~2회 30분~60분 운동 - 5g/kg 권장
					- 주 3회 이상 90~120분 운동 - 7g/kg 권장
						- 체중 증가 고려 ->  10g/kg 권장
			- 체중 kg 당 필요 단백질
				- 근력 증가를 위해 운동
					- 1.6g/kg 권장
			- 근비대 필요 칼로리
				- 1일 에너지 초과 필요량 350~470kcal
					- 체중 변화에 맞춰서 지속적으로 점진적으로 증가시킬 것
			- 1.6g/kg 이상의 단백질 섭취로 인해 간이나 신장 등의 손상은 증명된 바 없다.
			- 운동을 처음 시작하는 사람들이나 장년층에서 운동하는 경우에는 체중 kg당 요구 단백질이 더 높을 수 있다.
				- 처음 6개월 동안은 2.0g/kg 까지 증가시켜 섭취하는 것이 좋다.
			- 탄수화물이 4g/kg 이하로 떨어질 경우 글리코겐이 부족
			- 골격근 증가를 위해서는 + 350kal 정더로 전체적인 에너지 섭취량을 증가 시키고 단백질은 1.6g/kg 으로 고정, 나머지 열량에서 탄수화물 섭취는 운동 강도나 기간에 따라 5~8g/kg 수준에서 조절하고 나머지 열량은 지방으로 사용
		- 저체중과 영양 섭취
			- 실제 에너지 섭취가 적은 경우
				- 실제로 내가 먹는 칼로리를 다 계산 해볼 것
			- 기초대사량이 비상적으로 높은 경우
				- 제대로 된 식단으로 해결 가능
			- 소화기 문제로 흡수가 제대로 되지 않는 경우
				- 소량 씩 여러번의 식사를 하는 방법이 가장 적합
				- 물리적으로 한번에 과량 식사를 하는것은 도움이 되지 않는다.
				- 소화가 잘되는 음식을 골라 적은 양으로 자주 먹는 것이 가장 좋다.
				- 식사의 빈도
					- 아침, 점심, 저녁, 간식으로 4회로 시작
					- 점진적으로 5~6회로 늘릴 것
		- 다이어트
			- 목표 체중을 새로운 설정값으로 인지시키지 못하면 항상성 시스템이 작동해서 뇌가 기억하고 있는 원래의 체중으로 돌아가게 된다.
			- 한번에 먹을량을 2번에 나누어서 먹을 것
				- 위의 팽창을 줄이기 위함
		- 운동 전/중/후 식사 타이밍
			- 우리몸은 뇌에 의해 조절
				- 자율신경계
					- 교감신경 - 급박한 상황 (고강도 운동)
						- 전신에 걸쳐 에너지를 쓰는 신경
					- 부교감신경 - 평소 (밥먹거나 쉴 때)
						- 소화기계를 비롯하여 특수하게 국한된 지역에만 작용하며 에너지를 저장하는 신경
				- 운동하기 직전에 식사를 한다면 뇌는 혈액 공급의 우선순위에 대한 혼란을 겪게 됨
					- 골격근 소화기계 모두 제대로 혈액을 공급받지 못함
					- 소화 불량
					- 운동 비효율
			- 운동 전 영양 섭취
				- 탄수화물 - 에너지 전환 이용이 빠름
					- 운동과 식사 시간의 간격이 짧을수록  탄수화물 식품에 치중하여 섭취할 것
				- 탄수화물, 지방, 단백질을 적절한 비율로 섭취 할 경우  소화에 평균 2~3시간 소요
					- 지방의 비율이 높을수록 소화 시간 연장
					- 순수하게 탄수화물만 섭취 할 경우 1시간 이내로 소화
				- 식사 후 혈당 증가로 인한 인슐린 작용 정상화 평균 2시간
					- 인슐린 증가 -> 운동에너지 제공 (글루카곤, 코르티솔, 카테콜아민) 호르몬 사용 불가 -> 저장된 에너지 사용 불가 -> 운동 수행능력 감소
				- 최대 퍼포먼스
					- 탄수화물 60~70%, 단백질 0.3%~0.4%, 지방 10% 비율로 운동 3시간 전에 섭취
				- 운동 2시간 전에 식사
					- 지방 제거
					- 탄수화물 & 단백질로 구성
					- 1~2g/kg 탄수화물, 0.3~0.4g/kg 단백질로 구성
				- 운동 1시간 전에 식사
					- 탄수화물로만 구성
					- 식이섬유 적은 것으로 구성
					- 전분이나 단당류 공급하는 전분으로 구성
					- 과일이 가장 좋다
						- 포도, 바나나, 사과, 스포츠 음료, 꿀
			- 운동 중 영양 섭취
				- 수분과 전해질 섭취에 초점을 둘것
					- 땀 분비량이 많을 경우 이는 운동능력의 감소로 이어짐
					- 이온 음료
					- 한번에 마시지 말고 조금씩 나누어서 일정한 간격으로 섭취할 것
					- 운동 중 섭취한 아미노산은 빠르게 당신생을 거쳐 에너지원으로 동원됨
						- 운동 강도가 매우 높아야함
			- 운동 후 영양 섭취
				- 가장 중요하다
				- 운동후 식사는 빠르게 이루어져야 한다.
				- 운동후 식사 타이밍
					- 교감신경 -> 부교감 신경의 활성화가 기준
						- 배고픔이 기준
					- 교감신경에서의 섭취는 소화불량을 유발
				- 1~2g/kg 탄수화물과 0.4g~0.8g/kg 단백질을 섭취 권장
				- 다음 운동과의 간격이 12시간이 넘어갈 경우 단순당이나 아미노산은 섭취할 필요 없다
		- 공복 운동은 가능할까?
			- 공복이란 9시간 이상 금식한 상태
			- 지방을 먹을경우 12시간 이상 금식한 상태
			- 체중 관리의 목적
				- 기상 직후 500~1000ml 정도의 물을 나눠서 섭취하고 20~30분정도의 웜업운동을 통해 교감신경을 활성화되면 만족할 만한 운동을 할 수 있다.
			- 공복 운동 후의 식사는 반드시 먹을 것
				- 1~2g/kg 탄수화물과 0.4~0.8g/kg 단백질을 포함한 식사를 해줄 것
				- 단백질과 탄수화물은 필수
